## 2. 核心改造（`microbench/replaced_pdf.py`）

### 2.1 保护区：从「逐条取矢量 rect」到「聚类 + 合并」

```python
page.cluster_drawings()      # PyMuPDF 1.24+：直接拿聚类后的矢量图矩形
_merge_nearby(rects, gap=3)  # 再把相邻的块合并
```

**实测**（JACERS 综述首页，PyMuPDF 1.27.2.3）：
- 渐变图在 PDF 里是 **251 条渐变矢量** → 旧实现逐条取 rect，每条面积 **226**
  （刚好卡在「面积 < 200 当分隔线跳过」的阈值**之上**）→ 无一面积 > 5000 → **保护形同虚设**。
- 改后：251 条 → 聚成 **1 块**；纯正文页 → **0 块**（不误伤）；4 张子图的页 → 精确聚出 4 张。

### 2.2 涂改：从「块矩形」到「原页真实行」+ **减去保护区** + **不刷底色**

- **删掉**按块 bbox 的 redaction（它会实心填充压到图上）。
- 只涂**原页真实存在的文字行**，且每块涂改范围都过 `_clip_to_protected()`：
  保护区**外扩 1pt** 再做矩形相减（`_subtract_rect`），减完为空 → **这一行不涂**（保留英文）。
- 整块落在图里的块 → **整块跳过**（`stats.blocks_in_figure`）。
  实测 JACERS 首页的「Review」艺术字就属于这种情况：旧实现把它当成正文 →
  图上盖出 210×35.6pt 白矩形 + 译文被放大成巨大黑字「综述」压在图上。
- **`add_redact_annot(rect, fill=None)`**（2026-11-24 补）——
  redaction 只该「删掉文字」，**不该再刷一层底色**：
  ① `fill=bg` 会把页面的**彩色背景**冲成纯白（探针：彩色底 (229,216,153) → (255,255,255)）；
  ② 每涂一行多一个**白色实心矩形** —— JACERS 第 8 页（纯文字页）实测多出 **163 个**，
     它们是**可选中的空白块**，还让文件变大；
  ③ 多一层压图风险。
  → 删掉文字后**露出页面自己的背景**才对（扫描件的米色底也保住）。
  实测效果：**替换页的矢量对象数与原文页完全相等**
  （p1 255=255 / p2 8=8 / p3 1=1 / p4 448=448 / p5 593=593 / p6 0=0 / p7 5=5 / p8 0=0），
  旧版分别是 366 / 106 / 93 / 593 / 737 / 82 / 174 / 89。

### 2.3 图内文字判定：**短** 且 **离图近**，两条同时成立

```python
FIGURE_LABEL_MAX_LEN = 30      # 短行
FIGURE_LABEL_RADIUS = 20.0     # 离图近
```

**为什么不能只看一条**（实测数据）：
- 只看「离图近」：正文行离图最近只有 **2.1pt**，图注离图 **7.2pt** → 都会被误伤。
- 只看「短」：远处的一句短正文（"See Fig. 3."）会被误伤。
- 字号也**不可用**：刻度 8.0pt vs 正文 9.0pt，差太小。

→ 图内**刻度/轴名/子图号**保持英文不翻；**图注照翻**（它是论文文字）。

### 2.4 CJK 排版：自研 `_CjkTypesetter`

**为什么不用 `insert_textbox`**：MuPDF 的折行是**按空格分词**的 → 一长串中文在它眼里是
「整个一个词」→ 放不下就整体推到下一行 → 行末留一大片白。
实测 250pt 宽的行只排了 **193.5pt**，下一行只有 **120pt**。而且 `insert_textbox`
**从框顶起排、没有基线概念**，与周围未翻译的英文行基线对不齐。

实现要点：
- `_split_atoms()`：汉字/全角 → **单字原子**（任意处可断）；拉丁 → **整词原子**（不拆）。
- `wrap()`：贪心断行 + **避头尾**（`_NO_LINE_START` / `_NO_LINE_END`）+ **标点悬挂**。
- `positions()`：**逐原子两端对齐**（拉伸上限 0.4 字宽）+ **中英交界 0.5 字宽**（Unicode UTR #59）。
- 量宽用 `fitz.Font.text_length()`（精确），不是估。
- 落位用 `fitz.TextWriter` **逐行基线定位** → 字体以 `Type0/Identity-H` 正确嵌入、中文可搜索。

### 2.5 视觉行归并 + 基线去重

PyMuPDF 会把**一个视觉行**拆成**多条** line 记录（下标 / 字间距 / 字体切换）。
不合并 → 基线列表里出现相差 **0.05pt** 的两条基线 → 中文两行排到同一条基线 → **渲染成一团黑**。

- `_visual_lines()`：基线差 ≤ 0.35×字号 **且** 水平间隙 ≤ 2×字号 → 合并。
  （水平间隙这条专门防「左右两栏的同行」被并成一行。）
- 基线去重：±0.5pt。

### 2.6 小节标题独立落位（**不 bump 版本闸门**）

抽取层把小节标题吸进上一段末尾（实测 JACERS p1 的 i=4 源文本尾部是 `I. Introduction`）。
→ 译文末尾多出「I. 引言」，贴在正文最后一句后面，像排版坏了。

修法：在**替换版内部**把标题从译文尾部切出来，单独落到它自己的那行基线上。
- `_heading_num()` 识别 `I.` / `II.` / `1.` / `1.1` / `(A)`；
- `_split_heading_tail()` **绑定原文编号**再切（否则「…的 ME 系数」这种以拉丁字母结尾的句子会被误切）；
- ⚠ **不动抽取层 → 不 bump `BLOCK_TRANSLATION_VERSION` → 用户已有的段落译文不用重翻。**

### 2.7 几个**刻意**的决定（看着像 bug，其实是决定，别改）

| 现象 | 决定 | 理由 |
|---|---|---|
| 替换页里还留着 `Fig.8.` / `Table III.` | **图号/表号保留英文** | 它们是**图表的标识**，图表本身不翻 → 编号跟着不翻；图注**正文**照翻 |
| 替换页里留着 `I.` / `II.` | 那是**翻译后的标题**「I. 引言」「II. 实验方法」 | 标题编号**故意保留原编号**，方便与原文对照（探测器会误报成英文残留） |
| 段落之间有**大片空白** | **不填满原框** | 中文比英文短 → 行数变少 → 段末自然留白（BabelDOC Algorithm 1 语义）。强行撑开会变得稀疏 |
| 公式、表格还是英文 | `REPLACEABLE_KINDS` 只含 body/heading/text | 公式硬拼 LaTeX 极易装反分子分母；表格重绘会毁版式。用户要「图表保持不变」 |
| 参考文献里的作者名还是英文 | 引用条目**不翻** | 属于引文信息，翻译反而妨碍检索 |
| `blocks_unfit=2`（JACERS p4/p5 两处极窄块） | **保留英文，不截断** | 红线：放不下就保留英文原文，绝不写半截译文 |

调研结论（详见调研文档）：

- 值得借鉴的只有 **pdf2zh**（38,596★）与 **BabelDOC**（9,892★）两条线；
  **zotero-pdf-translate / pot-desktop / translate-shell / Translators 都不做 PDF 覆盖**，别再投时间。
- pdf2zh 的内容流算子过滤（丢 `T*` 文字算子、留图形算子）是「擦文字层、留矢量」的范式，
  但它的 `do_f/do_B` 被置空 → **图表降级重画** → 与「图表保持不变」的红线**直接冲突** → 只借思想。
- BabelDOC 的 `create_alternating_pages_dual_pdf()` 与我们「原文页+替换页交替」**同格式**
  → 路线获独立验证；其**排版三段式**（放得下就放 → 放不下才扩框 → 再不行降级）、
  **中英交界 0.5 字宽**、**标点悬挂**、**行距自适应**可直接借鉴（已落地）。
- **合规**：pdf2zh / BabelDOC / zotero-pdf-translate 均为 **AGPL-3.0** → 只借思路、**不抄源码**，
  落地代码一律自行重写。
- **依赖**：两者都依赖 **DocLayout-YOLO** → 会打破本项目「可离线、无模型依赖」的属性 → 不引入。

## 4. 新增坑位（AGENTS.md §4.133~§4.136）

| # | 一句话 | 教训 |
|---|---|---|
| §4.133 | 保护区要**聚类**，不能逐条取矢量 rect | 渐变图 = 上百条矢量；逐条取 → 保护区被切碎 → 形同虚设 |
| §4.134 | redaction 是**实心填充** → 涂改范围必须**减去**保护区 | 压到图上一丁点 = 图上多一块白斑 |
| §4.135 | MuPDF 的折行是**拉丁语义**；中文要自己断行 + **逐行基线**落位 | 塞进 `insert_textbox` 只会得到行末大片留白 + 基线对不齐 |
| §4.136 | 「没翻过」的页必须靠**总页数**减出来，不能靠遍历快照 | 只遍历快照 → 从未翻过的页静默留英文 |
